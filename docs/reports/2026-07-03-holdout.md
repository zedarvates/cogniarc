## Bugs Bloquants Identifiés

### 🐛 B1 — `domain_profiler.py:273` : `DomainClassifier` n'a pas d'attribut `.result`

```python
# domain_profiler.py:273
domain = self.base_classifier.result or "unknown"   # ← CRASH
evidence = self.base_classifier.evidence              # ← aussi absent
```

`DomainClassifier` expose `.classify()`, pas `.result`/`.evidence`. La refactor de `domain_classifier.py` (wrapper mince autour de `classify_game_type()`) a cassé l'ancienne API. Symptôme : `"⚠️ Cross-game import failed: 'DomainClassifier' object has no attribute 'result'"` à chaque run holdout.

**Fix :** Ajouter les propriétés `.result` et `.evidence` à `DomainClassifier.__init__` ou modifier `domain_profiler.py` pour appeler `.classify()`.

### 🐛 B2 — Nano-LLM boucle sur action 6

Le Nano-LLM (qwen2.5:0.5b) retourne systématiquement `action=6` avec `conf=0.80` dès que la phase machine stagne, même sur des jeux où l'action 6 est inefficace. Le prompt ne contextalise pas assez l'observation courante.

### 🐛 B3 — Pas de fichier `agent.log`

Le répertoire du projet n'a aucun fichier `*.log`. Les erreurs ne sont visibles que dans stdout des runs. Aucune persistance des erreurs pour monitoring.
